The workspace bar, one strip across the top

A chromeless window pinned to the top of the screen, above everything, never taking focus. Every tab is the same width and holds three logical columns: the slot number in accent blue, the activity dot, and a two-line title. Slots are permanent addresses — pressing an unused F-key creates that workspace, closing one frees its number without renumbering anything else.

01 Anatomy of a tab

Three columns, no visible dividers. The number is the dominant mark — 21px Rajdhani in clavis blue, dim at 55% until the tab is active. The title drops the uppercase label treatment and uses the title role instead (Rajdhani, sentence case) at chrome scale, so it reads as a name rather than a category — losing the caps and the 0.14em tracking makes it noticeably quieter even before the size drop.

03 The three activity states

Idle is a steady grey dot. Working is blue and pulsing at 600ms — motion means work in progress. Waiting for input is a steady yellow dot: yellow is the sanctioned warning signal, so it says "this one needs you" without borrowing the motion that already means something else. Colour carries urgency, motion carries progress — two independent channels, so a blocked workspace and a busy one never look like two speeds of the same thing.

04 Slots are permanent addresses — live

Press an unused F-key and that workspace is created in that slot, sliding in where its number belongs. Close one and its tab slides out, leaving a gap in the numbering — slot 3 stays slot 3 forever, so the key you learned never moves under you. Both transitions run at the app's one duration: 250ms, CubicEaseOut. Try it.

Buttons stand in for the real gestures — F5..F7 activate-or-create, and exit closes the workspace you are in. Watch slot 4 keep its number when 2 or 3 closes.

This changes the data model. The slot is a stable address, not an ordinal, so closing a workspace must not reflow the others — the plan's original "close reflows ordinals" is wrong and becomes "close frees the slot". A new workspace takes the lowest free slot, so the gap left by closing 2 is what the next + fills.

05 Closing a workspace vs quitting Clavis

exit now means "close this workspace" — it disposes that session and removes the tab, and the rest of the app carries on. That leaves the application with no way out, so the bar's right end gains a quit glyph beside +, backed by a quit palette command. Quit is the one genuinely destructive gesture in the bar, so it is the only element that turns red on hover and the only one that confirms first.

One question this opens. What happens when you close the last workspace? Either the bar sits empty with just + and quit — the app persists with nothing open, which is coherent now that quit is separate — or closing the last one is refused. Empty is my recommendation: it is the honest consequence of separating the two gestures, and the bar still gives you a way back in.

06 The identity accent — kept

Decided: the tick stays, and its length never changes. A workspace's identity is not a function of whether you happen to be looking at it, so the mark must not grow or shrink on selection — only its opacity lifts from 55% to full. The second preview keeps the accent-free version on record for comparison.

Kept, and confined. A workspace should feel like a place, not just a number. The cost is a third colour language on a 48px strip, so the accent is fenced in tightly: it is only ever this 2px tick, it never touches the number or the dot, and its geometry is fixed. That leaves the three languages cleanly separated — blue number = position, dot = state, tick = identity — with only the dot carrying motion.

07 F12 — the overview

Architecturally just a panel kind (workspace-overview) placed as a top-edge slide-in, so it inherits open/close/Esc/restore/tear-off for free. It answers what the bar cannot: where each workspace points, which model it runs, how long it has been in its current state, and how full its context is. Note the gap at slot 3 — workspace 3 was closed and its number stays reserved.

Mockup for the Workspaces feature (plan: WP-1) — approved. Three-column tabs of equal width, a 21px blue slot number, sentence-case two-row titles with hover tooltips, animated tab creation/closure at 250ms, stable slot numbering, an identity accent of constant length, and a quit affordance separate from exit. Remaining open question: what closing the last workspace does (section 05).
